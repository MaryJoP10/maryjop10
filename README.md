# Portafolio Personal — MaryJoP10

Portafolio web interactivo desarrollado para presentar mis proyectos, habilidades y experiencia como desarrolladora de software.

El diseño está inspirado en interfaces gaming, combinando una estética moderna con animaciones e interacciones para crear una experiencia visual dinámica.

## ✨ Características

- Diseño responsive para escritorio, tablet y dispositivos móviles.
- Interfaz inspirada en videojuegos.
- Animaciones e interacciones fluidas.
- Secciones para proyectos, habilidades y experiencia.
- Navegación intuitiva.
- Integración con proyectos publicados y repositorios de GitHub.
- Optimizado para diferentes tamaños de pantalla.

## 🛠️ Tecnologías

- **Next.js**
- **TypeScript / JavaScript**
- **Tailwind CSS**
- **Framer Motion**
- **React**
